# homebrew-ww

Homebrew tap for the `ww` CLI — the command-line companion to the
[Witwave](https://github.com/witwave-ai) autonomous-agent platform.

## Install

```bash
brew install witwave-ai/homebrew-ww/ww
```

The formula (`Formula/ww.rb`) is auto-generated and pushed by the
release-ww.yml workflow on every tagged release of the source repo.
